# Правила проекта для Claude Code

## Codex

- Codex подключай только по явной команде пользователя: `/codex-pipeline` или `/codex:*`. Без такой команды Claude Code и Codex работают раздельно.
- Субагента `codex:codex-rescue` сам не вызывай, даже если застрял или хочешь второе мнение. Если считаешь, что помощь Codex полезна, предложи это пользователю текстом и жди его команды.
- Не запускай `codex-companion.mjs task` без явной команды пользователя. `task --help` не выводит справку, а запускает реальную задачу.
